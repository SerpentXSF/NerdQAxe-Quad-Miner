NerdQAxe Quad Miner

Mine up to 4 pools at once on a NerdQAxe++ — open source.

Flash a fresh device from your browser (no tools to install).

Your browser can't do Web Serial. Use Chrome or Edge on desktop, or flash with esptool. Web Serial needs a secure (https) page and permission to access the serial port.

Requires Chrome or Edge on desktop. Plug the NerdQAxe++ in with a USB-C data cable, click the button, pick the serial port, and confirm. This does a full flash.

Already running the firmware? You probably don't need this page. Update over the air instead: open your device's web UI, go to the firmware update page, and upload esp-miner-NerdQAxe++.bin (the firmware) and www.bin (the website, so it matches the firmware). Upload them under exactly those names — the update page checks the filename and rejects anything else. No cable, and your pool config is kept. Grab those files from the latest release.

After flashing

The device will drop off your network — this is normal. A full flash erases saved settings, including WiFi, so the miner will not come back at its old IP address. It boots into a temporary setup access point instead. This is expected, not a brick.
  • On a phone or laptop, join the miner's own WiFi network (an open AP named like NerdQAxe-xxxx). A setup page opens automatically; use it to connect the miner to your home network.
  • Find the miner's new IP (your router's device list, or it re-appears on the network), open its web UI, go to Settings, set Pool mode to Dual, and add 1–4 pools with a weight each.
  • The dashboard shows every pool's live hashrate.

Prefer the command line?

Download nerdqaxe-quad-miner-factory-v*.bin from the releases page and:

pip install esptool
python -m esptool --chip esp32s3 --port <PORT> write-flash 0x0 nerdqaxe-quad-miner-factory-v*.bin

Add --no-stub if esptool stalls on the ESP32-S3 USB-Serial/JTAG port.
